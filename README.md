# Trokaria

Código do aplicativo de [`trokar.ia.br`](https://trokar.ia.br/).

O aplicativo usa PHP e MySQL. Configure `TROKAR_INSTALL_TOKEN` no ambiente PHP antes de uma instalação nova. O instalador grava `app/config.php` e cria as tabelas. Consulte [INSTALL.md](INSTALL.md).

Mantenha credenciais, cópias do banco, dados de usuários e arquivos enviados pelos usuários no ambiente da hospedagem. Este repositório guarda o código e os arquivos estáticos da aplicação.
